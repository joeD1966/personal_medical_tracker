# SecureMed - Personal Medical Data Tracker

SecureMed is a secure-looking personal medical tracking web application designed as an educational and learning project. It starts with a comprehensive sign-in screen with account registration, password recovery (email/SMS), and bypass options.

## Features Included
- **Sign-In Launch Page**: Full sign-in, account registration, and password recovery tabs right on startup.
- **Administrator Demo**: Username `administrator` / Password `1234`.
- **Recovery & Bypass Options**: Verification codes via Email/SMS or instant bypass.
- **Prescriptions, Blood Pressure, Appointments, Contacts, and Health Notes**.
